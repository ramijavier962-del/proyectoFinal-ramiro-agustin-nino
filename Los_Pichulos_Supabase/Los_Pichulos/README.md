## 📌 Descripción del proyecto

**Los Pichulos** es un sistema web desarrollado para facilitar la administración de un negocio de venta de ropa.

El sistema permite gestionar los productos, controlar el stock disponible, registrar ventas y consultar información importante del negocio desde una plataforma sencilla y organizada.

El objetivo principal es mejorar el control de la mercadería y facilitar las tareas administrativas del comercio.

## 🎯 Objetivos

- Administrar los productos del negocio.
- Registrar y controlar las ventas.
- Consultar el stock disponible.
- Organizar la información de manera ordenada.
- Generar reportes para facilitar el seguimiento del negocio.

## ⚙️ Funcionalidades principales

- **Inicio de sesión:** acceso al sistema mediante autenticación.
- **Gestión de productos:** registro y administración de prendas.
- **Control de stock:** consulta de las existencias disponibles.
- **Registro de ventas:** almacenamiento de las operaciones realizadas.
- **Reportes:** consulta de información sobre ventas y productos.
- **Configuración:** administración de datos del sistema.
